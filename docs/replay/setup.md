# Per-instance setup: fork base, layout, budget

Read when cutting a fork base, adapting layout, or setting the char budget and cost ceiling — single-fork mechanics, clone-ref hardening, and the measurement-call procedure.

- ONE fork of the upstream, ever — GitHub allows exactly one per account, so per-instance forks are impossible. Corrected rule: SINGLE fork; before each rewind push an archive branch `replay-<id>-final` at the merged sha (the terminal state is never orphaned — pinned on a named branch); then force-push fork main to the next instance's base. (single-fork addendum; DECISIONS.md fork-strategy line.)
- Fork main = historical base + layout-adaptation commit (e.g. `mkdir tests; git mv pypika/tests/*.py tests/; git mv pypika/tests/dialects tests/dialects`, clickhouse excluded — disclosed as adaptation on top of base). The harness force-fetches origin main (lap.py:91-93) — pointing at live upstream hands the agent the fix; the pinned fork makes the fetch a no-op.
- Deployment = FRESH `git clone --single-branch --branch main <fork-url>` — a plain clone carries upstream refs incl. the fix; `git log --all` reaches it (clone-ref hardening addendum). Never reuse a full upstream clone as the deployment checkout.
- Per-base CHECKOUT_CHAR_BUDGET: measure `wc -c` over every CODE_PATHS-matched file at the base, sum, ×1.25 headroom, set env at launch. Measure, never default — truncation stops mid-iteration in sorted order and silently drops the alphabetically-late files, which is where fixes concentrate (queries.py, terms.py).
- CODE_PATHS = source-only view (e.g. `pypika/*.py`, tests excluded) — mutation-apply rejects files outside the view (lap.py:200-202), so the implementer cannot self-green by weakening tests (Aider's hidden-tests principle). `**` does NOT recurse — each nested dir needs its own glob.
- Assert the fix's target file is IN the emitted view (run checkout_files at base, grep block headers) — never "the budget covers the package".
- Per-instance measurement call BEFORE launch: one real implementer call at the measured view size; stop threshold 80% of the COST_CEILING_USD=$0.01/lap — over it the lap dies at gate='cost', a harness-attributed kill. If it approaches, raise the ceiling per instance (disclosed) or scope CODE_PATHS to the fix module. Measured pypika source-only ~200k chars ≈ $0.00008/call — ~100× under. (cost-ceiling addendum.)
