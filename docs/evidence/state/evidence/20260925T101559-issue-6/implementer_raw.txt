   ```python
   def _not_found(self) -> None:
       self._send_json(404, {"error": "not found"})
   ```

   `_send_json` already emits `Content-Type: application/json` plus a `Content-Length`-bounded body. So acceptance criteria 1–3 are satisfied by the existing implementation; criteria 4 and 5 are covered by the existing round-trip / health tests.

2. **Conclusion about code.** No behavior change to `app.py` is needed. The risk is regression, so the valuable work here is pinning the contract with tests: exact JSON body, exact `Content-Type`, and the end-to-end verification flow from the issue.

3. **Add regression tests** to `app_test.py` (keeping the existing style/helpers):
   - unknown id → 404, `Content-Type: application/json`, body exactly `{"error": "not found"}`;
   - unknown id body parses as JSON `{"error": "not found"}`;
   - `/paste` with no id also returns the JSON 404 (same shared `_not_found` path);
   - the issue's verification flow: POST → GET 200 → GET unknown id 404 with the JSON fragment.

4. **Run the suite, then commit** on branch `agent/issue-6`.
